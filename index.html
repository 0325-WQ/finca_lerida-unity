Finca Lérida — Recorrido Virtual 360° y Garaje

Prototipo interactivo desarrollado en Unity 6 con URP, sistema de entrada nuevo (Input System), navegación 360°, exploración del garaje/bodega con ajuste de altura y controles adaptados para PC y dispositivos Android.

1. Arquitectura y Contenido de la Escena

Entorno y Navegación

Escena configurada con Skybox 360°, recorrido libre/interactivo, área de garaje/bodega y limitación de altura de cámara sobre terreno y estructuras.

Controles Multiplataforma

Script FincaLeridaTourAR.cs integrado con el nuevo Input System para teclado/ratón en PC y controles táctiles/botones en pantalla en Android.

Compilación Android

Configuración orientada a Android (API 24+, IL2CPP, ARM64) con interfaz adaptable y generación de paquete .apk.

2. Flujo de Trabajo en Git y GitHub

Para mantener el repositorio limpio y ordenado, se utiliza un archivo .gitignore que excluye carpetas pesadas o generadas automáticamente por Unity (como Library/, Temp/, Logs/, UserSettings/ y binarios *.apk).

  1. Inicialización y rama main: se inicializó el repositorio y se subió la base del proyecto a origin/main.
  2. Rama de trabajo feature/*: los cambios y ajustes se desarrollan en ramas dedicadas, por ejemplo feature/correccion-camara-apk.
  3. Pull Request y fusión: se abre el Pull Request hacia main en GitHub, se revisa y se fusiona para registrar la trazabilidad del trabajo.
git checkout main
git add index.html
git commit -m "docs: agregar pagina de presentacion para GitHub Pages"
git push origin main

3. Publicación del APK mediante GitHub Releases

Dado que los archivos .apk se excluyen del control de código fuente mediante .gitignore, la distribución pública se realiza desde GitHub Releases:

  1. Abre el repositorio en GitHub y entra a Releases → Create a new release.
  2. Crea la etiqueta v1.0.0 apuntando a la rama main y escribe un título descriptivo (por ejemplo, Finca Lérida Tour v1.0.0 — Android APK).
  3. Arrastra el archivo .apk compilado al área de adjuntos (Attach binaries) y haz clic en Publish release.
  4. Copia el enlace del archivo adjunto o usa /releases/latest en el botón de descarga de esta página.
Nota sobre GitHub Pages: Esta página web funciona como portal informativo y de descarga del proyecto; la ejecución nativa de la aplicación de Unity se realiza instalando el archivo .apk en un dispositivo Android.
